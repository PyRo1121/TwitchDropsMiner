# Translation catalog status

Catalog schema version: `2`  
Help source revision: `2`

The English catalog embedded in `translate.py` is the runtime schema. Each JSON catalog in this directory has explicit values for every schema key and is checked for key, type, and placeholder compatibility.

**Schema completeness is not a native-language quality approval.** The schema-version-2 catalog expansion was machine-assisted and received terminology/error correction, but native-speaker review remains external and pending for every locale. The `non_identical_to_english` count printed by the schema tests is only a literal byte-inequality metric; it does not measure translation correctness, fluency, or review status.

A locale may be marked Approved only after a named language owner reviews the complete catalog against the matching English schema and records the reviewed schema version. Until then, UI copy should be treated as unapproved machine-assisted translation.
